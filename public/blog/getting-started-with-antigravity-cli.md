A comprehensive guide to setting up your first agentic development workflow.

The Antigravity CLI is your gateway to agentic development. This tutorial will walk you through installation, configuration, and your first automated task.

## Installation

```bash
npm install -g antigravity-cli
```

## Your First Task

```bash
ag init my-project
cd my-project
ag run "Create a REST API with Express"
```

The agent will plan, implement, and test your API — all within a secure sandboxed environment.
